# Changelog — บันทึกข้อผิดพลาดที่พบและแก้ไข (2026-10-17 ถึง 2026-10-18)

สร้างย้อนหลังจากบทสนทนาทั้งหมดในเซสชันนี้ เรียงตามลำดับเวลาคร่าวๆ แยกตามหมวด
ใช้คอลัมน์ `หมวด` สำหรับทำกราฟสรุปจำนวนได้

| # | วันที่ | หมวด | ปัญหาที่พบ | การแก้ไข |
|---|---|---|---|---|
| 1 | 10-17 | correctness | SRT parser ตัดบล็อกผิดเมื่อ cue มีบรรทัดว่างแทรกอยู่ภายใน (อีเมลในซับ Oshi no Ko ทำให้ error "Invalid SRT segment ID: Yoshizumi here.") | เปลี่ยนตัวแบ่งบล็อกจาก blank-line เป็นมองหา "เลข ID + เวลา" แทน |
| 2 | 10-17 | correctness | ไฟล์ซับที่ export มี `[DEFAULT]:`/`[UNKNOWN]:` ติดเข้าไปในบทพูด | เพิ่มสถานะเหล่านี้เข้า exclusion set ใน `effective_character()` |
| 3 | 10-17 | correctness | `score_active_speakers()` ใช้ `localized=False` ทำให้สัญญาณปากขยับอนิเมะเจือจางจนแทบเป็นศูนย์ | เปลี่ยนเป็น `localized=True` |
| 4 | 10-17 | correctness | `install_guard()` ไม่มี try/except ทำให้แอป crash ตั้งแต่เปิดถ้าเครื่องไม่มี Xcode CLT | ครอบ try/except ให้ fallback ได้ |
| 5 | 10-17 | correctness | สแกนเสียงที่ได้ไฟล์เปล่า/เสีย รายงานว่า "เสร็จแล้ว" ทั้งที่ไม่มีผลลัพธ์ | เช็ก `valid_audio()` ซ้ำหลัง ffmpeg เขียนไฟล์เสร็จทุกขั้น |
| 6 | 10-17 | correctness | วิดีโอเล่นค้างหลัง error ครั้งเดียว กดเล่นซ้ำไม่มีอะไรเกิดขึ้น | เพิ่ม flag `_media_error` ให้ลองโหลดใหม่จริง |
| 7 | 10-17 | correctness | `add_media()` มี race condition ตอนเพิ่มไฟล์พร้อมกันสองทาง | ครอบด้วย `self.lock` |
| 8 | 10-17 | correctness | detection class ที่ไม่รู้จักทำให้ scan ทั้งวิดีโอล้ม | เปลี่ยนเป็นข้าม + warn แทนการ raise |

| 10 | 10-17 | correctness | สถานะ `SCRIPT_CONFLICT` โชว์ confidence ของตัวละครที่ตรวจพบจริง แต่ติดชื่ออื่น | ตั้ง `score=0.0` เมื่อขัดแย้ง |
| 11 | 10-17 | correctness | log error ของ subprocess เปิดอ่านไม่ระบุ encoding ข้อความไทยอาจเพี้ยน | เพิ่ม `encoding="utf-8"` |
| 12 | 10-17 | ux | GUI ไม่โชว์ progress ระหว่างแยกเสียง (ขั้นหนักสุด) ทั้งที่ worker พิมพ์ progress ไว้อยู่แล้ว | เพิ่ม `on_line` callback ให้ `run_process()` อ่าน log มาอัปเดต UI สด |
| 13 | 10-17 | ux | ตัวเลขเวลาเล่นวิดีโอความกว้างไม่เท่ากัน ทำให้ปุ่ม/แถบเลื่อนสั่นเวลาเล่น | เปลี่ยนเป็น monospace font |

| 15 | 10-18 | feature | เลือกหลายแถวในตาราง observations ไม่ได้ (เรียงลำดับก็ไม่ได้) | เปิด sorting + ผูกด้วย ID แทน row index |

| 18 | 10-18 | feature | ส่งหลายกลุ่มเข้ากลุ่มเดียว (เช่น "ภาพประกอบ") ทีเดียวไม่ได้ | เพิ่ม `merge_selected_profiles()` |
| 19 | 10-18 | ux | คีย์ลัดฟังช่วงถัดไป `Ctrl+→` ใช้ไม่ได้บน Mac (ชนกับ Mission Control ของ macOS) | เปลี่ยนเป็น `Shift+↓`/`Shift+↑` |
| 20 | 10-18 | correctness-critical | `confirm_pair()` มี silent failure 2 จุด (dialog default เป็น "No", ยกเลิกตอนเลือกตัวละครเองก็เงียบ) กดแล้วดูเหมือนสำเร็จทั้งที่ไม่ได้ผูกอะไรเลย | เพิ่มข้อความแจ้งผลทุกกรณี |
| 21 | 10-18 | correctness-critical | **`link()` ไม่ตั้ง `confirmed=1` ให้โปรไฟล์ที่ผูก ทำให้เครื่องมือจัดกลุ่มใหม่เข้าใจผิดว่าเป็นของว่าง แล้วลบทิ้งพร้อม link** (เป็นสาเหตุที่คู่เสียง-ภาพที่ยืนยันไปหายซ้ำสอง) | `link()` ตั้ง confirmed+lock ให้ทั้งคู่ทันที + กันสำรองไม่ให้ `reset_unlocked_memberships()` ลบโปรไฟล์ที่มี link ผูกอยู่เด็ดขาด |
| 22 | 10-18 | correctness | ช่องค้นหาบทซับไม่ค้นหาในคอลัมน์ "สถานะ" ทำให้หา "หลายเสียง"/MULTIPLE_SPEAKERS ไม่เจอ | เพิ่มคอลัมน์สถานะ+บทพูดเข้าการค้นหา |
| 23 | 10-18 | reporting | รายงาน "99.3%" ที่ให้ไปวัดแค่ "สัดส่วนเสียงที่จัดกลุ่มสำเร็จ" ไม่ใช่ความถูกต้องของชื่อในซับจริง ทำให้เข้าใจสถานะงานผิด | ตรวจสอบซ้ำแล้วรายงานตัวเลขที่ถูกต้องระดับบรรทัดซับ (MANUAL 0%, PROPOSED 73%, ยังไม่มีชื่อ 27%) |

## เครื่องมือใหม่ที่สร้างระหว่างเซสชัน (ไม่ใช่บั๊ก แต่เป็นงานพัฒนาเพิ่ม)

| สคริปต์ | หน้าที่ |
|---|---|
| `scripts/difficulty_heatmap.py` | Heatmap จุดที่ระบบมีปัญหา เทียบกับเวลาประมวลผลจริง |
| `scripts/recluster.py` | จัดกลุ่มใหม่จากที่ยืนยันแล้ว โดยไม่ต้องสแกนซ้ำ |
| `scripts/accuracy_report.py` | เทียบข้อเสนอ AI กับที่มนุษย์ยืนยัน คิดเป็น % ความแม่นยำ |
| `scripts/voice_av_correction.py` | ใช้หลักฐานปากขยับจากคู่ที่ยืนยันแล้ว แก้เสียงที่คล้ายกันจนจัดกลุ่มผิด |
| `scripts/review_backlog.py` | รายการบรรทัดซับที่ต้องตรวจ จัดลำดับตามตัวละครที่มีบทเยอะสุดก่อน |
